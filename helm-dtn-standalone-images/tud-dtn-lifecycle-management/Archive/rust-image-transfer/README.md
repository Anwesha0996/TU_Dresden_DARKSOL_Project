# Archived Rust image-transfer implementation

This directory preserves the earlier Rust-based image-transfer implementation,
its local/demo deployment environments, generated demonstration evidence, and
supporting documentation.

It is retained for research history only and is not part of the active
implementation. The repository root contains the current Go-based `helm-dtn`
standalone OCI image-transfer workflow.

The archived files retain their former repository-relative layout so that the
implementation and its documentation can still be studied together.
