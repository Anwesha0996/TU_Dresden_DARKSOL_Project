# helmdl

## General Overview
This component loads a dependency list generated by `helmdd` and downloads all dependencies specified therein. This primarily includes container images, but `helmdl` is built in a way to support implementing downloaders for other dependencies (e.g. cloning Git repositories).

The process of downloading dependencies is rather simple:
1. Parse the dependency list generated by `helmdd`
2. Create temporary directories for downloading the required resources
3. Sequentially call the downloaders for the individual dependency types
   1. Check whether the requested resource is available locally
      - If it is: Use the local version
      - If it isn't: Download it

## Adding a new resource type to download
To add a new resource type for `helmdl` to download, the code has to be modified in some places. In the following, it will be explained using the example of Git repositories. It is assumed that you've already followed the documentation to add this new resource type to `helmdd`.

### 1. Creating a directory to save this resource into
In the `DownloadDependencies` function, there is a section containing the setup of directories to save the resources into:
```go
imagesDir := filepath.Join(runTempDir, "Images")

os.Mkdir(imagesDir, os.ModePerm)
```

For the purpose of adding a Git repository download, we add the following:
```go
imagesDir := filepath.Join(runTempDir, "Images")
gitDir := filepath.Join(runTempDir, "Git") //<- path to the Git download directory

os.Mkdir(imagesDir, os.ModePerm)
os.Mkdir(gitDir, os.ModePerm) //<- create the directory
```

### 2. Implementing a downloader
With the download directory available, we now need to implement a downloader for this resource type. For the example of Git repositories, the downloader is simply running a `git clone` for the URL detected by `helmdd`.
```go
// getGitRepos executes git clone to fetch any repositories required by the application
func getGitRepos(gitList map[string]string, saveDir string) error {
	for repo := range gitList {
		log.Printf("helmdl: Cloning repository %v...\n", repo)

		cmd := exec.Command("git", "clone", "--recurse-submodules", "-j8", repo, filepath.Join(saveDir, gitDir))

		stderr, _ := cmd.StderrPipe()
		if startErr := cmd.Start(); startErr != nil {
			log.Printf("helmdl: failed to clone %v: %v", repo, startErr)
			return startErr
		}

		if runErr := cmd.Wait(); runErr != nil {
			log.Printf("helmdl: failed to clone %v: %v", repo, runErr)
			return runErr
		}
	}
	return nil
}
```

### 3. Implement the check for local resources
As mentioned, we want to avoid downloading resources that are already available locally. For images, this can be easily done by checking if (a) the image is in the list of images returned by our local Docker client, and (b) the digest of the image matches the latest available remote version (if no specific version tag was provided). For Git repositories, the process is a bit more involved. We need to check if the repo has been cloned before (i.e. there is a directory with the same name in a specific directory `helmdl` checks) and if the `HEAD` hash matches with the remote `HEAD`:
```go
// getGitRepos executes git clone to fetch any repositories required by the application
func getGitRepos(gitList map[string]string, saveDir string) error {
	for repo := range gitList {
		// Check if we've already cloned this repo
		gitDir := path.Base(strings.TrimSuffix(repo, ".git"))
		if directoryExists(filepath.Join(saveDir, gitDir)) {
			// Repo has been cloned before, next check if it's still the latest version
			// -> HEAD hash matches with remote
			cmd := exec.Command("git", "ls-remote", repo, "HEAD")
			out, err := cmd.Output()
			if err != nil {
				log.Fatal(err)
			}

			remoteCommitHash := strings.Fields(string(out))[0]
			localCmd := exec.Command("git", "-C", gitDir, "rev-parse", "HEAD")
			out2, err := localCmd.Output()
			if err != nil {
				log.Fatal(err)
			}

			hash := strings.TrimSpace(string(out2))

			if remoteCommitHash == hash {
				log.Printf("helmdl: Repository %v already available in latest version! Skipping pull...", repo)
				continue
			}

			// Hash didn't match
			// -> we want to clone the newer version
			// -> delete old directory
			if removeErr := os.RemoveAll(gitDir); removeErr != nil {
				log.Printf("helmdl: unable to remove directory '%v': %v", gitDir, removeErr)
			}
		}
		log.Printf("helmdl: Cloning repository %v...\n", repo)

		cmd := exec.Command("git", "clone", "--recurse-submodules", "-j8", repo, filepath.Join(saveDir, gitDir))

		stderr, _ := cmd.StderrPipe()
		if startErr := cmd.Start(); startErr != nil {
			log.Printf("helmdl: failed to clone %v: %v", repo, startErr)
			return startErr
		}

		if runErr := cmd.Wait(); runErr != nil {
			log.Printf("helmdl: failed to clone %v: %v", repo, runErr)
			return runErr
		}
	}
	return nil
}
```
With these additions, `helmdl` can now check whether a specific Git repository is available locally in the latest version and clone it if it isn't. To be able to update the `git clone` commands to point to the local repository, the `helmdp` component has to be modified. This is explained in its README.
